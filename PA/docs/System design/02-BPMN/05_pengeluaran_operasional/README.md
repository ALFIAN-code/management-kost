# Alur 05: Pencatatan Pengeluaran Operasional (Operational Expenses)

> Modul Terkait: **Modul Opsional (Finance & Billing)**  
> Sifat: **Aktif pada Properti yang Mengelola Arus Kas Mandiri**

---

## 1. Deskripsi Alur
Alur ini mengatur pencatatan seluruh pengeluaran kas riil yang dikeluarkan oleh pengelola untuk kebutuhan operasional gedung (seperti pembelian token listrik PLN, pembayaran air PAM, internet/WiFi, gaji staf/penjaga, dan pembelian perlengkapan kebersihan).

## 2. Akuntabilitas & Transparansi
Setiap pencatatan biaya mewajibkan:
* Pemilihan kategori biaya (Utilitas, Pemeliharaan, Gaji, Perlengkapan, Lainnya).
* Pengunggahan foto nota/bukti struk fisik sebagai lampiran audit.

## 3. Laporan Laba Bersih Otomatis
Sistem secara otomatis menghitung laba bersih (*Net Operating Income*) gedung dengan rumus:
$$\text{Laba Bersih} = \text{Total Penerimaan Sewa \& Denda} - \text{Total Pengeluaran Operasional}$$
Data ini disajikan pada dashboard pemilik properti secara *real-time*.
