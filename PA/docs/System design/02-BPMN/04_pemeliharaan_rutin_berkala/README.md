# Alur 04: Pemeliharaan Rutin Berkala (Preventive Maintenance)

> Modul Terkait: **Modul Opsional (Maintenance & Facility)**  
> Sifat: **Aktif jika Pengelola Memiliki Jadwal Perawatan Terencana**

---

## 1. Deskripsi Alur
Alur ini mengelola agenda perawatan berkala fasilitas bersama dan peralatan gedung (contoh: kuras tandon air 3 bulanan, servis berkala pendingin ruangan AC 6 bulanan, penyemprotan fogging, dan inspeksi pompa air).

## 2. Peringatan Otomatis (Reminder)
Sistem secara otomatis menampilkan pengingat di dashboard pengelola ketika tanggal pelaksanaan servis memasuki H-7, sehingga perawatan dapat dijadwalkan tepat waktu sebelum terjadi kerusakan fasilitas.

## 3. Integrasi ke Modul Finance (Arus Kas Keluar)
Setelah pekerjaan servis fisik selesai, pengelola dapat langsung memasukkan biaya jasa teknisi atau pembelian suku cadang ke Modul Finance (Pengeluaran Operasional) jika modul Finance aktif.
