DFD Level 0 — Diagram Konteks Sistem Manajemen Rumah Kost Multi-Gedung

Standar Notasi DeMarco / Yourdon · satu proses sentral 0.0, tujuh entitas luar

Karakteristik DFD Level 0 (Diagram Konteks) Standar Akademis:

  • Proses Tunggal (0.0): Seluruh cakupan sistem diwakili oleh satu lingkaran sentral bernomor 0.0. Tidak ada proses terpisah pada level konteks.
  • Entitas Luar (External Entities): Kotak persegi panjang yang merepresentasikan asal mula input (sumber) dan tujuan output (muara).
  • Bebas Data Store: Sesuai kaidah formal Yourdon & DeMarco, diagram konteks tidak menampilkan simbol penyimpanan data (Data Store) karena penyimpanan berada di dalam internal sistem 0.0. Dekomposisi penyimpanan dijelaskan pada DFD Level 1.
  • Tujuh Entitas Luar: tiga aktor manusia (Pemilik, Pengelola, Penghuni) dan empat sistem eksternal (Keycloak sebagai penyedia identitas OIDC, Midtrans sebagai gerbang pembayaran, WhatsApp Gateway sebagai layanan pesan, serta Model Bahasa AI sebagai host MCP).
  • Pembeda Aliran: Garis Biru menunjukkan Aliran Masuk (Input Data / Parameter) dan Garis Merah menunjukkan Aliran Keluar (Output Informasi / Respon / Laporan).
