# Glosarium PA — Istilah Naskah

> Sinkron dengan `Docs/01_guides/GLOSSARY.md`. Tambahan istilah akademik.

**Terakhir diupdate:** 2025-09-19

| Istilah | Definisi | Dipakai di |
|---|---|---|
| Rumusan Masalah | Pertanyaan penelitian (4-5 butir, diawali "Bagaimana...") | BAB1 |
| Batasan Masalah | Ruang lingkup + yang explicitly tidak dikerjakan | BAB1 |
| Kajian Pustaka | Landasan teori + penelitian terdahulu | BAB2 |
| Penelitian Terkait | Tabel perbandingan + gap statement penutup | BAB2 |
| Desain Sistem | Solusi + Scrum + diagram + ERD + mockup + skenario | BAB3 |
| Skenario Aplikasi | Tabel uji black-box per peran | BAB3 |
| Skenario Evaluasi | Kuesioner Likert (Sangat Kurang s/d Sangat Baik) | BAB3/BAB4 |
| Increment | Hasil sprint yang demo-able | BAB3 |
| Modulith | Lihat Docs glossary — tulis konsisten, jangan ganti jadi microservice | BAB1-3 |
